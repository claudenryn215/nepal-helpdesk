## Quick Answers

| Problem | Common cause | Fix |
| --- | --- | --- |
| Category mismatch error | Wrong category chosen | Use the category tree exactly; check prohibited items |
| Image rejected | Size or content violation | Use 800x800+ JPEG, white background, no logos |
| Listing stuck 'under review' | Backlog or content issue | Wait 24-48h; check the rejection reason if returned |


## Step 1: Choose the right category

1. Use the category search in Seller Center — choose the most specific node.
2. Wrong categories get auto-rejected; check the category requirements.
3. Prohibited or restricted categories (e.g., some electronics, health items) need approval.

## Step 2: Prepare images correctly

1. Main image: at least 800x800 pixels, JPEG, white background.
2. No watermarks, text overlays, or logos on the main image.
3. Upload 3-5 angles; marketplace quality photos convert better.

## Step 3: Set correct price and stock

1. Price must be within the category's allowed range.
2. Don't set prices above the maximum — use the price history tool if unsure.
3. Keep stock quantity accurate to avoid order cancellations.

## Step 4: Fill attributes completely

1. Complete all required attributes (brand, model, color, size).
2. Incomplete attributes cause listing errors.
3. Use the 'Quick Setup' template if available for your category.

## Step 5: Handle 'under review' listings

1. New listings are reviewed within 24–48 hours.
2. If returned, read the rejection reason under the product status.
3. Fix the exact reason and resubmit — do not edit randomly.

## Step 6: Bulk upload errors

1. Download the current template for your category.
2. Fill it exactly; keep SKU names unique.
3. Upload and check the error report — it lists each failing row.

## Troubleshooting

| Problem | Cause | Fix |
| --- | --- | --- |
| SKU duplicated error | Same SKU used twice | Make every SKU unique; re-upload |
| VAT/tax field error | Missing tax info | Fill VAT number or tax code in Seller Profile > Tax |
| Listing not searchable | Missing keywords | Add search terms in the listing title and description |

## FAQ

**Q:** Why is my Daraz listing not approved?

**A:** Mostly category mismatch, image violations, or missing attributes — check the reason in Seller Center.

**Q:** Can I edit a live listing?

**A:** Yes, edits go back through review, so batch changes carefully.

**Q:** How many images does Daraz require?

**A:** At least one 800x800+ main image; 3+ images are recommended.
